# Compatibilité
| Plateforme | Statut |
|---|---|
| Windows 11 x64 | Cible initiale |
| Windows 10 x64 | Cible initiale, à valider selon l'édition et les composants installés |
| Windows 8.1 / 7 / XP | Hors première version ; étude d'une édition héritée séparée |

La compatibilité doit être testée sur des systèmes réels ou machines virtuelles représentatives. Ce document n'est pas une certification.
