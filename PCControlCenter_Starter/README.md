# PC Control Center — Starter

Squelette initial de PC Control Center, pas encore une version complète ni un installateur prêt à distribuer.

## Cible initiale
- Windows 10/11 x64
- C# / WPF / .NET Framework 4.8
- Architecture modulaire, interface noire et bleu électrique
- Fonctionnement local prioritaire

## Ouvrir
1. Installer Visual Studio avec « Développement Desktop .NET ».
2. Ouvrir `PCControlCenter.sln`.
3. Compiler en Debug.
4. Le tableau de bord est une maquette : aucune mesure matérielle réelle n'est branchée.

## Prochaines étapes
1. Collecteurs CPU/RAM réels.
2. Inventaire système et stockage.
3. Adaptateurs de capteurs matériels après vérification des licences.
4. Historique, diagnostics, tests et packaging installateur/portable.

Pas de suppression automatique de fichiers personnels, de modification de BIOS/tensions/fréquences, ni de service Windows obligatoire.
